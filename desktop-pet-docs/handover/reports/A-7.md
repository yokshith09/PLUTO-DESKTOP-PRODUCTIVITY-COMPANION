# A-7 — Still working

## What changed

Pluto now remembers when a Claude Code chat starts work after the person sends a prompt. If that chat is still working after 25 minutes, the pet says so once. It says so once more at 60 minutes. A finish, a question, a permission request or an error stops the timer. Pluto keeps this only in memory and only has its one-minute check running while at least one chat is working.

Chats are kept separate by assistant and folder. A new prompt to the same chat starts its timer again. Runs more than three hours old are quietly forgotten.
