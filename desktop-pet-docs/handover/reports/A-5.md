# A-5 — Your day with assistants

## What changed

Pluto can now give one calm evening summary of the assistant chats it knows about today. It counts finished chats and permission requests, and may mention the folder with the most finished chats when there is a clear winner. It does not score a person or compare days.

The line appears only once a day between 17:30 and 21:30, through Pluto's existing notification budget. It is saved as shown only if the pet actually displayed it.
