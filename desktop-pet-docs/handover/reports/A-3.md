# A-3 — Finished while you were away

## What changed

When a Claude Code, Codex, Cursor or OpenCode chat finishes, needs the person or asks for permission while the person has been away for at least ten minutes, Pluto remembers it in memory. When keyboard or mouse input resumes, Pluto shows one short welcome-back bubble. Several chats are combined into one bubble. A restart forgets the list.

The list is limited to ten chats, keeps the strongest message for each assistant and folder, and discards messages more than eight hours old. Pluto only checks for the person's return while this list is non-empty. The existing focus guard holds the welcome-back bubble during a focus session, as it does for other assistant bubbles.
