# A-2 — Chats in Project Activity

## What changed

Pluto now remembers when an assistant finishes, needs you, or asks permission in a project's folder. Those moments appear in that project's existing Activity list with the assistant's name and time. Pluto stores only the assistant name, the last folder name, the kind of moment, and the time—never the request text, transcript, tool name, or full folder path.

Events are kept locally in Pluto's existing preferences. The newest 500 are retained, and an identical repeat in the same folder within a minute replaces the earlier entry.
