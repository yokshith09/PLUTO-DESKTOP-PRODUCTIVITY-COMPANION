# K-1 Timetable (Study › Timetable)

**Owner decision (2026-11-09):** the timetable in the Study v3 preview is approved ("timetable - fine"). Reference: open `desktop-pet-docs/design/study-v3-preview.html` in a browser, tab **Timetable**. Build that, with Pluto's own components and tokens (not the preview's CSS).

## What to build
1. **Study page tabs.** `src/features/student/StudyPage.tsx` gets three tabs: **Courses** (everything the page shows today, unchanged: course list, exams, weekly report), **Timetable** (this task), **Exams, notes, tasks** (K-2; add the tab with a "Coming soon" empty state only). Remember the open tab in pref `study.tab`.
2. **Data.** Migration `013_classes.sql` in `desktop-pet-docs/docs/05-backend/migrations/` and registered as version 13 in `crates/pluto-core/src/db/migrate.rs`:
   `classes(id TEXT PK, course_id TEXT NULL REFERENCES courses(id) ON DELETE SET NULL, title TEXT NOT NULL (1..80, used when no course), day INTEGER 0..6 (0 = Monday), start_min INTEGER 0..1439, end_min INTEGER > start_min and <= 1440, place TEXT (0..40), teacher TEXT (0..40), repeat TEXT IN ('weekly','odd','even','once'), once_date TEXT NULL (YYYY-MM-DD, required when repeat='once'), remind_min INTEGER NULL IN (10,30) — used by K-3, created_at INTEGER) STRICT`.
   Core module `crates/pluto-core/src/classes.rs` (pattern: `courses.rs`): list, add, update, delete, `replace_all` (for import, in one transaction), plus validation errors with plain messages. Export the type to TypeScript (`ts-rs`, then `pnpm gen:types`).
3. **IPC.** Commands in `src-tauri/src/ipc.rs` (`classes_list`, `class_add`, `class_update`, `class_delete`, `classes_import`), registered in `src-tauri/src/lib.rs`, client functions in `src/ipc/client.ts`, mock handlers with a demo week in `src/ipc/mock.ts`.
4. **Week grid.** The whole week visible at once, Monday first; days as columns, times as rows; a class is a block placed by its exact start and end, coloured by its course. Today's column and a "now" line are marked. Click a block to edit it; click an empty spot to add a class there (snapped to the slot length).
5. **View settings** (pref `study.timetable`, JSON): day starts (6:00–12:00), day ends (14:00–23:00), slot (30/60/90 min), days shown (Mon–Fri, Mon–Sat, Mon–Sun), row height (compact/comfortable/roomy). Defaults 8:00, 18:00, 60, Mon–Sun, comfortable.
6. **Class editor** (inline panel or dialog, like the preview): course (or free title), day, starts, ends, place, teacher, repeats (every week / odd weeks / even weeks / just once + date), remind me (none / 10 / 30 minutes before; stored only, K-3 uses it). Save, Delete (with Undo toast), Close. Keyboard: every field reachable, Escape closes.
7. **Import and export.**
   - CSV columns exactly `course,day,start,end,place,teacher` (day `Mon`..`Sun`, time `HH:MM` 24-hour). Unknown course names create the course. Show a preview of the parsed rows and the errors per line, then "Replace my timetable" or "Add to it".
   - **.xlsx import** with the same columns in the first sheet. The owner approved **one** new dependency for this: the Rust crate `calamine` (read-only), in `src-tauri` (not in the core). Parse the rows into the same structure the CSV path uses.
   - Export CSV with the same columns (save dialog through the existing file-save pattern, or copy to clipboard if none exists).
   - A copyable ChatGPT prompt: "Turn this timetable image into CSV with exactly these columns: course,day,start,end,place,teacher. Use day names Mon to Sun and 24-hour times like 09:30. One row per class."
   - The file is read on the computer; nothing is uploaded.

## Acceptance
- Classes survive a restart; deleting a course keeps its classes (title falls back to the course name saved at import, or "Class").
- Overlapping classes on the same day sit side by side, never on top of each other.
- Times outside the shown day range are not lost: a small "2 classes outside 8:00–18:00" note offers to widen the range.
- CSV round trip: export then import gives the same timetable (test).
- Bad rows are reported by line number with a plain reason; good rows still import (test).
- Works at 800 px window width (the grid scrolls sideways inside its own box, never the page).

## Must not
No change to the Courses tab content; no new screen outside Study; no other new dependency; no network; no pet behaviour (that is K-3).
