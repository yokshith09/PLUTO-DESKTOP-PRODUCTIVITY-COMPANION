# K-3 Class reminders from the pet

Needs K-1 (classes with `remind_min`). The pet says when a class is about to start.

## What to build
1. In the shell, a timer that wakes at the next class start minus `remind_min` (only classes with a reminder, and only for the current week's matching days, respecting `repeat`: weekly, odd/even ISO week, once on its date). Re-arm after each fire and whenever classes change (emit/listen to the existing event bus or a new `ClassesChanged` event; follow how reminders re-arm today — read `crates/pluto-core/src/reminders.rs` and its shell side first).
2. The pet shows one bubble: `Physics in 10 min · Lab 3` (place only if set). Use the same path as other Pluto bubbles (`pet://say` / `show_on_pet`), and respect the focus guard and Quiet hours exactly as reminders do.
3. A switch in Settings is **not** needed: no reminder chosen = no bubble.
4. Pure logic in the core: `next_class_alert(classes, now_local) -> Option<(when, text)>` with unit tests for weekly, odd/even weeks, once, midnight edge, a class already started, and two classes at the same time (one bubble listing both).

## Acceptance
- Unit tests above pass; the shell part is **Unverified** until the owner sees a bubble on Windows.
- Changing or deleting a class re-arms the timer (test the re-arm trigger at the core level).

## Must not
No sound changes (A-8 is undecided). No notification outside the pet. No new setting key.
