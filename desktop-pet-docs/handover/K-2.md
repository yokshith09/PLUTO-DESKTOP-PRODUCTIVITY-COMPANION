# K-2 Exams, notes, tasks (one Study tab)

**Owner decision (2026-11-09):** "exams, notes, tasks can exist in a single tab". Reference: `desktop-pet-docs/design/study-v3-preview.html`, tab **Exams, notes, tasks**. Needs K-1's tab bar (do K-1 first, same branch base or after it is merged).

## What to build
1. **Course filter chips** at the top: All courses, then each course with its colour. The choice filters all three sections. Remember it in pref `study.planFilter`.
2. **Exams** as cards in a responsive grid: date block (month, day), course name and colour, "in N days" (use `countdownLabel` from `ExamCountdown.tsx`), title. Add exam (course, title, date) and delete (Undo) using the existing `exam_add` / `exam_delete` commands. Past exams are hidden behind "Show past exams".
   - No "topics per exam" and no readiness percentage: those need the syllabus, which is on hold with the course page. Leave a TODO comment pointing to `design/COURSE_PAGE_BRIEF.md` §3.
3. **Tasks** for the filtered courses (from `course_links().tasks` plus the normal task list): checkbox to complete, title, course dot and name, due date chip. "New task" opens the existing task creation with the course preset. Done tasks of the last 7 days are behind "Show done".
4. **Notes** for the filtered courses (from `course_links().notes`): title, course, last changed. Clicking opens the note in the Notes page (existing navigation). "New note" creates a note linked to the course.
5. Empty states for each section, in Pluto's wording style (short, kind).

## Acceptance
- Filter "Physics" shows only Physics exams, tasks and notes (test).
- Completing a task here completes it everywhere (same mutation as Tasks page; test).
- Works at 800 px: sections stack.

## Must not
No database migration (use what exists). No change to the Courses tab, Timetable, Tasks page or Notes page beyond reusing their hooks/components. No new dependency.
